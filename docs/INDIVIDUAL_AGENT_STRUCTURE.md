# Individual Agent Page Structure

The Agentic AI Library now gives every F-number a stable GitHub location.

- F01-F26 remain standalone repositories.
- F27-F30 remain individual full packages under `systems/`.
- F31-F170 each have an individual folder under `systems/` with a README, a direct launcher command, and links to the shared runnable domain implementation and domain specification.

This preserves the unified implementation architecture while making every agent independently discoverable and directly linkable from GitHub.

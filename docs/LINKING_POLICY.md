# Stable Agent Linking Policy

Each F-number should have one stable GitHub destination.

- F01-F26 link to their standalone repositories.
- F27-F30 link to their individual package folders inside `agentic_ai_library`.
- F31-F170 link to their individual system folders inside `agentic_ai_library`; each page links onward to the shared runnable implementation and specification for its domain.

Catalog links should point to these stable destinations rather than to temporary branches or non-existent per-agent files.

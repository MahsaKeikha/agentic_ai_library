ACCESSIBILITY

The Atlas should be usable by more people.

Accessibility is treated as an ongoing engineering responsibility across desktop and mobile experiences.

Effective August 24, 2026

Current approach

The website uses semantic headings, labeled forms, keyboard-accessible controls, visible focus behavior, responsive layouts, descriptive image alternatives, and status messages for interactive forms where implemented.

Known limitations

Some dense architecture views, diagrams, and interactive simulations may require further improvement for screen readers, keyboard-only navigation, reduced motion preferences, or high zoom levels. Public documentation may also contain complex tables that are easier to navigate on larger screens.

Feedback

If you encounter an accessibility barrier, email mahsa@connectioncare.net. Please include the page address, the problem encountered, the browser or assistive technology used when helpful, and the format or accommodation that would make the material usable.

Improvement process

Accessibility issues are reviewed alongside other website defects. Improvements are recorded through the same public release and change process used for the Atlas.

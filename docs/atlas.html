HOW TO USE THE ATLAS

Compare systems by architecture, not by buzzword.

Open several systems in the same domain and compare role decomposition, orchestration, tools, state, memory, evaluation, failure behavior, and protected actions. The value of the library is not that every system looks identical. It is that the same engineering questions become visible across very different domains.

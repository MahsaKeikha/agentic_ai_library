I am opening the **Agentic AI Library**: a growing set of runnable agent patterns for people who build, teach, and lead with AI systems.

This is a companion to my work on the AI Engineering Handbook and my course. The point is not another chat demo. The point is structure you can reuse:

- specialized agents  
- narrow tools  
- memory on disk  
- a clear orchestrator  
- a human gate before anything is sent, applied, or approved  

**Flagships already live** (clone and run offline):

- Book writing pipeline  
- Academic research lab  
- Biotech R and D planning (documentation level, not wet lab)  
- Technical support desk  
- Online shop cases  
- Debug and automation incidents  
- Senior software design package  
- CEO daily exec pack  

Each repo is written so a new engineer can run it with `python3` and see the pipeline without an API key. Live model calls are optional.

**Long term aim:** a curated index of hundreds of agentic patterns (flagships for depth, micro examples for breadth) that students and teams can cite the same way they cite a good handbook chapter.

If you teach, send your cohort to the index. If you ship systems, steal the checklists. If you only have five minutes, open one flagship README and read the human gate section.

I will keep adding patterns in public. Feedback and careful contributions are welcome when they respect the template and the safety limits.

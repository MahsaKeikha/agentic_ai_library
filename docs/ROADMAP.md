## Engineering-grade checklist

Every unified system should satisfy [`systems/STANDARD.md`](../systems/STANDARD.md) and preserve appropriate architecture/scope, agent roles, orchestration, state, evidence handling, safety boundaries, evaluation, human gates, failure handling, example workflows, integration points, and deployment notes.

## Build policy

- Prefer runnable offline reference workflows over empty README-only packages.
- Never convert missing material evidence into invented facts.
- Preserve stable IDs once released.
- Sensitive domains require explicit boundaries and escalation.
- Human approval must not erase unresolved safety, evidence, quality, legal, clinical, financial, or operational risks.
- F27 onward use the unified architecture unless intentionally promoted to a standalone flagship.

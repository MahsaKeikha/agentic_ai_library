# Unified Agentic Systems

This directory contains the local implementation layer for the F27-F170 portion of the Multi-Agent AI Atlas. The same systems are also published as standalone repositories so readers can study one architecture at a time.

The local packages make cross-domain comparison, shared testing, and engineering maintenance possible. The standalone repositories provide stable public entry points. Neither location, by itself, establishes maturity, independent review, or production authorization.

## What is included

- F27-F30: dedicated executive and strategy packages
- F31-F170: domain packages, shared batch implementations, tests, and evaluation documents
- explicit agent roles and orchestration paths
- deterministic tools and structured state where appropriate
- evidence, safety, escalation, and human approval controls
- examples and tests appropriate to each package's current maturity

Package depth varies because this is a living engineering collection. Use the [maturity registry](../docs/MATURITY_REGISTRY.md) for verified L3 status, not directory presence or README language.

## Start with the evidence

1. Read the shared [engineering contract](STANDARD.md).
2. Use the [complete catalog](../docs/INDEX.md) to locate a system.
3. Inspect that package's README, architecture notes, implementation, tests, and evaluation material.
4. Check the [maturity registry](../docs/MATURITY_REGISTRY.md) before making any maturity claim.
5. Treat consequential outputs as decision support until qualified review and explicit authorization are complete.

These packages are reference implementations and educational engineering resources. Production use requires organization-specific validation, security and privacy review, domain expertise, operational controls, monitoring, and accountable human authority.

# F30 Agentic Corporate Governance

Multi-agent workflow for governance operations and board-process support. It supports governance calendars, policy registers, board-material readiness, decision logs, action tracking, compliance reminders, risk escalation, and a human/legal review gate.

Not legal advice. The system does not determine directors' duties, make filings, certify compliance, or replace corporate counsel or the board.

## Agents

- Governance Intake
- Calendar and Obligations Analyst
- Policy Register Analyst
- Board Process Analyst
- Decision Log Analyst
- Action Tracker
- Governance Risk Analyst
- Governance Brief Writer
- Gatekeeper

## Quick start

```bash
python3 systems/F30_agentic_corporate_governance/run.py --offline
```

# F28 Architecture

F28 separates startup acceleration into five visible specialist agents. Agents use reusable skills and deterministic tools. The workflow preserves context, memory, safety gates, and trace events. Evaluation checks specialist coverage and evidence handling. Human approval is required before consequential external actions.

## Layers

1. AGENTS: venture intake, market, product, growth, and investor readiness roles
2. TOOLS: market sizing, experiments, unit economics, runway, and milestone operations
3. SKILLS: reusable startup analysis procedures
4. orchestration: workflow coordination
5. memory: local execution memory
6. schemas: structured context
7. prompts: behavior guidance
8. safety: approval and stop conditions
9. observability: execution tracing
10. evals and benchmarks: quality validation

# F91-F100 Education Evaluation Framework

These systems are evaluated as education and academic-operations support tools. They do not replace instructor, committee, or institutional authority.

## Common criteria

- Missing learner, course, evidence, or policy context is explicit.
- Human review is required before publication, submission, grading, disciplinary action, or institutional certification.
- Academic-integrity workflows preserve due process and do not generate automatic misconduct findings.
- Laboratory planning preserves safety review before execution.
- Tests cover registration, missing context, high-stakes gate behavior, and approval controls.

## System-specific focus

| ID | Evaluation focus |
|---|---|
| F91 | pedagogical alignment, lecture clarity, assessment alignment, accessibility |
| F92 | outcome alignment, sequencing, standards mapping, inclusion, assessment coherence |
| F93 | explanation quality, scaffolding, mastery tracking, misconception handling |
| F94 | blueprint coverage, question quality, difficulty calibration, bias, answer-key correctness |
| F95 | learning objectives, procedure clarity, equipment readiness, safety, assessment alignment |
| F96 | funding fit, timeline accuracy, compliance completeness, budget consistency |
| F97 | evidence quality, citation context, false-positive control, due-process preservation |
| F98 | solicitation alignment, evidence support, narrative coherence, budget narrative, compliance |
| F99 | scope, methodological rigor, literature coverage, analysis validity, reproducibility |
| F100 | standards coverage, evidence traceability, gap accuracy, outcomes evidence, action tracking |

## Red-team scenarios

Test incomplete course context, contradictory policies, biased assessment items, inaccessible content, answer leakage, attempts to auto-accuse a student, unsafe lab assumptions, fabricated citations, unsupported grant claims, and attempts to bypass instructor or institutional approval.

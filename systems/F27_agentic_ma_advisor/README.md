# F27 Agentic M&A Advisor

Multi-agent decision-support workflow for acquisition screening and diligence. It supports target intake, strategic fit, financial review, synergy hypotheses, integration risk, diligence questions, deal memo drafting, and a human approval gate.

Not legal, tax, accounting, valuation, or investment advice. No autonomous transaction, offer, commitment, or filing.

## Agents

- Target Intake
- Strategic Fit Analyst
- Financial Review Analyst
- Synergy Analyst
- Integration Risk Analyst
- Diligence Lead
- Deal Memo Writer
- Gatekeeper

## Quick start

```bash
python3 systems/F27_agentic_ma_advisor/run.py --offline
```

# F81-F90 Science Evaluation Framework

These systems are evaluated as scientific research and decision-support workflows, not as substitutes for qualified scientific review, institutional oversight, or safety controls.

## Common criteria

- Claims are traceable to supplied evidence or explicitly marked as assumptions.
- Missing evidence remains visible.
- Uncertainty and competing explanations are preserved.
- Hazardous experimental execution requests do not advance through the offline reference workflow.
- Human review cannot erase unresolved scientific or safety risks.
- Tests cover system registration, evidence discipline, hazard blocking, and approval behavior.

## System-specific focus

| ID | Evaluation focus |
|---|---|
| F81 | model validity, mathematical consistency, falsifiability, experimental testability |
| F82 | algorithm/circuit correctness, hardware realism, error sensitivity, benchmark reproducibility |
| F83 | property evidence, candidate-ranking transparency, validation quality, uncertainty |
| F84 | literature grounding, simulation assumptions, property evidence, safety boundaries |
| F85 | dataset quality, model assumptions, scenario transparency, uncertainty communication |
| F86 | mission assumptions, subsystem interfaces, trajectory/payload consistency, verification coverage |
| F87 | observation quality, signal validity, catalog provenance, uncertainty, reproducibility |
| F88 | demand/generation balance, storage assumptions, reliability, cost/economic sensitivity |
| F89 | high-level systems reasoning, safety evidence, verification, regulatory traceability |
| F90 | search completeness, screening consistency, extraction accuracy, synthesis quality, citation integrity |

## Red-team scenarios

Test contradictory papers, fabricated-looking citations, incomplete datasets, hidden assumptions, stale measurements, p-hacking-like selective evidence, benchmark leakage, unit mistakes, impossible parameter combinations, attempts to convert simulation outputs into unsupported real-world certainty, and attempts to bypass institutional or safety review.

# F121-F130 Marketing and Growth Evaluation Framework

These systems are evaluated as marketing and communications decision support.

## Common criteria

- Claims are traceable to supplied evidence.
- Missing customer, channel, market, or performance context is explicit.
- Human approval is required before public publishing, mass messaging, or paid-spend changes.
- Privacy, consent, and deceptive-claim risks block progression.
- Offline examples do not publish, send, or transact.

## System-specific focus

| ID | Evaluation focus |
|---|---|
| F121 | brand coherence, audience fit, positioning clarity, messaging consistency |
| F122 | factual accuracy, usefulness, search intent fit, content quality, publication readiness |
| F123 | technical SEO validity, keyword relevance, internal linking, measurable impact |
| F124 | channel fit, tone, moderation risk, scheduling quality, public-release discipline |
| F125 | segmentation quality, journey relevance, experiment design, lifecycle metrics |
| F126 | budget discipline, attribution assumptions, audience quality, creative review, spend controls |
| F127 | positioning, launch readiness, persona evidence, sales enablement quality |
| F128 | narrative accuracy, media relevance, reputational risk, spokesperson readiness |
| F129 | hypothesis quality, experiment validity, statistical interpretation, rollout discipline |
| F130 | research quality, consent/privacy handling, synthesis fidelity, actionability |

## Red-team scenarios

Test fabricated testimonials, unsupported performance claims, prompt-like instructions embedded in customer feedback, biased segmentation, privacy-sensitive data, misleading attribution, vanity-metric optimization, accidental mass-send behavior, unauthorized budget increases, and pressure to publish before factual review.
